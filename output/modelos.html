Especificação

Os perfis definidos para este guia de implementação estão listados aqui. A seguir estão os perfis que foram definidos para cada seção. (R) denota uma seção obrigatória (ou seja, deve estar presente em um IPS), (S) denota uma seção recomendada, as demais são opcionais:

​ AllergyIntoleranceBRIPS

Alergia ou intolerância (geralmente: risco de reação adversa a uma substância)
​ BundleBRIPS

Esse perfil representa as restrições aplicadas ao recurso Bundle no Guia de Implementação do International Patient Summary (IPS).
​ CompositionBRIPS

Documento clínico usado para representar o conjunto de dados do International Patient Summary (IPS). Um documento de International Patient Summary (IPS) é um extrato de registro eletrônico de saúde que contém informações essenciais de saúde sobre um assunto de cuidado. O conjunto de dados IPS é mínimo e não exaustivo; independente de especialidade e independente de condição; mas ainda clinicamente relevante. Conforme especificado na EN 17269 e na ISO 27269, foi concebido para apoiar o cenário de utilização de «cuidados transfronteiriços não planeados», mas não se limita a ele. Pretende ser internacional, ou seja, fornecer soluções genéricas para aplicação global além de uma determinada região ou país. Este perfil é baseado no perfil ClinicalDocument.
​ ConditionBRIPS

Este perfil representa as restrições aplicadas ao recurso Condition no Guia de Implementação FHIR do International Patient Summary Um registro de um problema é representado no sumário do paciente como uma instância do recurso Condition restringido por esse perfil.
​ DiagnosticReportBRIPS

Este perfil restringe o recurso DiagnosticReport para representar testes de diagnóstico e relatórios de procedimentos em um sumário do paciente.
​ ImagingStudyBRIPS

Este perfil representa as restrições aplicadas ao recurso ImagingStudy pelo projeto IPS, que especifica as informações sobre um estudo de imagem DICOM do qual este resultado de imagem faz parte.
​ ImmunizationBRIPS

Este perfil representa as restrições aplicadas ao recurso de Imunização pelo Guia de Implementação FHIR do International Patient Summary (IPS). Um registro de uma imunização é representado no sumário do paciente como uma instância de um recurso de Imunização restrito por esse perfil.
​ MedicationBRIPS

Este perfil representa as restrições aplicadas ao recurso Medicação pelo Guia de Implementação FHIR do International Patient Summary (IPS), baseado no FHIR R4. Um medicamento é descrito no resumo do paciente como uma instância de um recurso Medication restrito por esse perfil.
​ MedicationRequestBRIPS

Este perfil representa as restrições aplicadas ao recurso MedicationRequest pelo Guia de Implementação FHIR do International Patient Summary (IPS), baseado no FHIR R4. Um registro de uma solicitação de medicação é representado no sumário do paciente como uma instância de um recurso MedicationRequest restrito por esse perfil.
​ MedicationStatementBRIPS

Este perfil representa as restrições aplicadas ao recurso MedicationStatement pelo Guia de Implementação FHIR do International Patient Summary (IPS), baseado no FHIR R4. Um registro de uma declaração de medicação é representado no sumário do paciente como uma instância de um recurso MedicationStatement restrito por esse perfil.
​ ObservationResultsBRIPS

Este perfil restringe o recurso Observation para representar vários tipos de resultados e observações associadas em um sumário do paciente. Este é o perfil base do qual derivam os outros perfis de resultados.
​ ObservationResultsLaboratoryBRIPS

Este perfil restringe o recurso Observation para representar resultados produzidos por testes laboratoriais ou painéis/estudos em um sumário do paciente.
​ ObservationResultsPathologyBRIPS

Este perfil restringe o recurso Observation para representar resultados produzidos por exames de patologia clínica em um sumário do paciente.
​ ObservationResultsRadiologyBRIPS

Este perfil representa as restrições aplicadas ao recurso Observation pelo projeto IPS, que especifica uma observação radiológica para o International Patient Summary com base no padrão FHIR R4.
​ OrganizationBRIPS

Espaço físico delimitado e permanente onde são realizadas ações e serviços de saúde humana sob responsabilidade técnica.
​ PatientBRIPS

Este perfil representa as restrições aplicadas ao recurso Patient pelo International Patient Summary (IPS) FHIR Implementation Guide e descreve as expectativas mínimas para o recurso Patient quando utilizado na Composition do IPS ou num dos referidos recursos.
​ PractitionerBRIPS

Este perfil restringe o recurso do profissional de saúde para representar um profissional de saúde que atua como observador dos resultados desta imagem.
​ PractitionerRoleBRIPS

Este perfil restringe o recurso PractitionerRole para representar um profissional que atua como observador dos resultados do Observation para uma organização específica.
​ ProcedureBRIPS

Este perfil representa as restrições aplicadas ao recurso Procedure pelo projeto IPS, que especifica uma entrada do Histórico de Procedimentos para o sumário Internacional do paciente com base no padrão FHIR R4.
​ VitalSignsBRIPS

Este perfil restringe o recurso VitalSigns para representar os sinais vitais do paciente.
​ SpecimenBRIPS

Este perfil restringe o recurso Specimen para representar as características de amostras biológicas no contexto de resultados laboratoriais integrados a um sumário do paciente.
